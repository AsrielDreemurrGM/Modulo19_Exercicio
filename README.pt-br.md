<h2>Visão Geral do Projeto</h2>
<p>
  This README is also available in <a href="./README.md">English</a>.
</p>
<p>
  Este projeto aplica boas práticas de CSS utilizando <strong>SMACSS</strong> e a
  <strong>Metodologia BEM (Block Element Modifier)</strong>. O arquivo CSS original foi
  reorganizado em arquivos SCSS modulares, compilados para CSS e vinculados a uma página HTML.
</p>
<h2>Tecnologias Utilizadas</h2>
<ul>
  <li>HTML5</li>
  <li>CSS3 / SCSS</li>
  <li>Metodologia SMACSS</li>
  <li>Metodologia BEM</li>
</ul>
<h2>Como Executar</h2>
<ol>
  <li>Clone o repositório.</li>
  <li>Instale as dependências com <code>npm install</code>.</li>
  <li>Execute o compilador SASS com <code>npm run sass</code> para observar e compilar SCSS em CSS.</li>
  <li>Abra o arquivo <code>index.html</code> no navegador para visualizar o resultado.</li>
</ol>
