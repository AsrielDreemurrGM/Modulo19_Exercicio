<h2>Project Overview</h2>
<p>
  Este README também está disponível em <a href="./README.pt-br.md">Português</a>.
</p>
<p>
  This project applies CSS best practices using <strong>SMACSS</strong> and the
  <strong>BEM (Block Element Modifier)</strong> methodology. The original CSS file was
  reorganized into modular SCSS files, compiled to CSS, and linked to an HTML page.
</p>
<h2>Technologies Used</h2>
<ul>
  <li>HTML5</li>
  <li>CSS3 / SCSS</li>
  <li>SMACSS methodology</li>
  <li>BEM methodology</li>
</ul>
<h2>How to Run</h2>
<ol>
  <li>Clone the repository.</li>
  <li>Install dependencies with <code>npm install</code>.</li>
  <li>Run the SASS compiler with <code>npm run sass</code> to watch and compile SCSS into CSS.</li>
  <li>Open <code>index.html</code> in your browser to view the result.</li>
</ol>
